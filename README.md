# کسب‌افزار

کسب‌افزار را پیشخوان فروش ساختم. فروش، مشتری و هزینه همان‌جا ثبت می‌شود که گزارش روز خوانده می‌شود. فاکتور می‌تواند لینک داشته باشد تا مشتری بدون ورود به پیشخوان آن را ببیند. ثبت از وب است، و از تلگرام و بله.

سایت: [kasbafzar.ir](https://kasbafzar.ir)

کسب‌افزار یک وب‌اپ است.

## English

I built Kasbafzar as the sales desk. A sale, a customer, and an expense are recorded in the same place the day's report is read. An invoice can carry a link so the customer can open it without entering the desk. Entry is the web, and also Telegram and Bale.

Site: [kasbafzar.ir](https://kasbafzar.ir)

Kasbafzar is a web app.

## پروژه‌های مرتبط

- [hamejoo-intro](https://github.com/mnhashemabadi/hamejoo-intro): همه‌جو را برای جستجوی آگهی ساختم؛ نتیجه روی همه‌جو می‌ماند و خود آگهی روی سایت منبع است.
- [alwer-intro](https://github.com/mnhashemabadi/alwer-intro): آلور را برای خریداری ساختم که درخواست بنویسد و پیشنهاد قیمت‌ها را کنار هم ببیند؛ آگهی فروش هم روی همان بازار است.
- [azadchi-intro](https://github.com/mnhashemabadi/azadchi-intro): آزادچی را برای آگهی و جستجو در مناطق آزاد ساختم؛ گفتگو با طرف معامله داخل آزادچی می‌ماند.
- [afzi-intro](https://github.com/mnhashemabadi/afzi-intro): افزی را برای کوتاه کردن یک نشانی ساختم؛ باز کردن لینک کوتاه همان صفحه را باز می‌کند.
- [alweryar-intro](https://github.com/mnhashemabadi/alweryar-intro): آلوریار را برای همکاری در بررسی آگهی و همکاری در فروش ساختم.
- [alwerchi-intro](https://github.com/mnhashemabadi/alwerchi-intro): آلورچی را برای فروشگاهی ساختم که کالا و موجودی‌اش در بازار آلور دیده شود.
